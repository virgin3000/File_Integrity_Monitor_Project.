# FIM — File Integrity Monitor

Учебный проект по информационной безопасности. Программа следит, чтобы файлы
в папке не менялись без ведома владельца (идея как у Tripwire / AIDE / OSSEC).

## Возможности
- `init` — создаёт эталон: SHA-256 каждого файла, сохраняет в `baseline.json`
- `check` — сравнивает с эталоном: **MODIFIED / NEW / DELETED**
- Эталон подписан **HMAC-SHA256** с секретным ключом — подмена базы обнаруживается
- Исключения: `.git`, `__pycache__`

## Запуск (Kali Linux, Python 3, без библиотек)
```bash
python3 fim.py init ~/test_folder   # создать эталон (спросит ключ)
python3 fim.py check                # проверить (тот же ключ)
```

## Безопасность и ограничения
- SHA-256, а не MD5/SHA-1: у них найдены коллизии.
- HMAC: хакер, изменив и файл, и базу, не сможет пересчитать подпись без ключа.
- Система обнаруживает изменения, но не предотвращает их.
- Эталон создаётся на заведомо чистой системе.
- Ключ нужно хранить отдельно от проверяемой машины.
